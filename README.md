# ValeAnalize V5

The approved supplied ValeAnalize logo artwork is used as the visual source for the embedded brand artwork and launcher icons.

V5 fixes the navigation/viewport behaviour, restores controlled Home-page scrolling, makes Settings and Analyse navigation functional, and adds the Guitar Focus workflow.

The GP-50 foundation follows Valeton's official GP-50 documentation. V5 does not claim a finished mastered song can reveal the original studio settings exactly; the matching engine must be validated against real GP-50 output in later DSP stages.
