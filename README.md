# ValeAnalize V4

**HEAR IT. ANALYSE IT. PLAY IT.**

V4 preserves the approved visual identity. It fixes the mobile viewport so the app fills the screen instead of leaving a large blank area; the Settings button now opens a working settings sheet; and the bottom Analyse button switches to the real Analyse screen.

V4 also adds a self-contained GP-50 database foundation and keeps the browser DSP analysis. Guitar Focus is deliberately described as conservative spectral preprocessing, not AI source separation.

GP-50 hardware facts are based on Valeton's official product/manual documentation and firmware V1.0.5.
